# 日本語文章スタイルガイド

日本語の文章を書くときは、以下のガイドラインをすべて適用してください。

## 見出し

- 名詞だけの見出しを避け、説明的にする
  - 悪い例：「設定」　良い例：「設定を3ステップで行う方法」
- 親の見出しが問いを示し、子の見出しでその答えがわかるように構成する
- 「AとB」形式の並列見出しを避ける。同じ見出しに入れる意図（比較・関係説明など）を見出し自体に示す
- 最小レベルの見出しでは1つの話題だけを扱う
- 見出しの階層は内容の論理構造を反映させる

## 文の構成

- 一文を短くする。複雑な修飾節は文を分割する
- 列挙には箇条書きを使う。横並びの列挙は読みにくい
- 一文の中で主語と述語を正しく対応させる
- 接続助詞「が」は多用しない。「が」を書いたら、そこで文を切れないか検討する

## 文の内容

- 読者の知識レベルを想定し、論理が繋がるように書く。くどくなっても論理の連続性を優先する
- 事実と意見を明確に書き分ける（「〜だ」と「〜と考える」を使い分ける）
- 根拠のない推測を書かない。「〜のはず」「〜と思う」で終わる文は避ける
- ぼかしことば（ほぼ・約・ほど・ぐらい・たぶん・ような・らしい）をできるだけ削る

## 語法

### 冗長な表現を省く

| 冗長な表現 | 言い換え |
|---|---|
| 〜してしまう・してしまった | 〜する・した |
| 〜のような・のように | 削除 |
| 〜という・といった | 削除 |
| 〜してみる・してみた | 〜する・した |
| 非常に・とても・大変（多用） | 削除（ここぞの場面だけ残す） |

### その他

- 指示代名詞（こそあど言葉）を避け、具体的に指す。「これは」より「このメソッドは」
- カナと漢字を使い分けて単語の境界を読みやすくする。同じ単語の表記は統一しなくてよい
- 漢語より和語を優先する
  - 当初の予測 → はじめの予測
  - 可能である → できる
  - 可及的速やかに → できるだけ早く
- 受動態を避け、能動態で書く
- 副詞は修飾する動詞の近くに配置する
  - 悪い例：ようやく、半年かけて開発してきた機能がリリースできた
  - 良い例：半年かけて開発してきた機能が、ようやくリリースできた
