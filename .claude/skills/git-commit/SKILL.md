# コミットメッセージ スタイルガイド

## モデル

コミットメッセージの生成には `claude-haiku-4-5-20251001` を使用する。
Agent ツールでサブエージェントを呼び出す場合は `model: "haiku"` を指定する。

## 形式

```
<プレフィックス>: <日本語の説明>

<本文（省略可）>

<Co-Authored-By（条件付き）>
```

## プレフィックス（全リポジトリ必須）

| プレフィックス | 用途 |
|---|---|
| `feat:` | 新機能の追加 |
| `fix:` | バグ修正 |
| `refactor:` | 動作を変えないコード改善 |
| `docs:` | ドキュメントの追加・修正 |
| `chore:` | ビルド・設定・依存関係の変更 |
| `test:` | テストの追加・修正 |
| `style:` | フォーマット等、コード動作に影響しない変更 |

## 件名ルール

- `<プレフィックス>: <日本語>` の形式
- 動詞で終える（「〜を追加」「〜を修正」「〜を変更」「〜を削除」）
- 72文字以内
- 末尾ピリオドなし・絵文字なし

## 本文ルール

- 変更が単純な場合は件名のみでよい
- 複雑な変更の場合は空行を挟んで本文を追加し、箇条書きで「何を・なぜ変えたか」を説明する

## Co-Authored-By

- Claude が**コードを書いた**場合のみ付与する:
  `Co-Authored-By: Claude Sonnet 4.6 <noreply@anthropic.com>`
- Claude がコミットメッセージのみを書いた場合は**付与しない**

## commit / push の自律実行

- `git commit` は確認なしで実行してよい
- `git push` は必ずユーザーに確認してから実行する

## 例

```
feat: ブログ記事の下書き保存機能を追加

- 編集中の記事を自動的にローカルストレージへ保存する
- 保存間隔は30秒に設定した
```

```
chore: anthropics/skills サブモジュールを最新コミットに更新
```
